# Classic XPilot maps

These are the maps that shipped with the original XPilot, unchanged, from
[github.com/ksoderbl/xpilot](https://github.com/ksoderbl/xpilot) (`lib/maps`). XPilot and these maps are
distributed under the GNU General Public License, version 2. See [COPYING](COPYING).

The game reads XPilot's `.xp` format directly. It carries over walls, bases, fuel, gravity wells, treasures,
teams, race checkpoints, edge wrapping and gravity. It leaves out what this game doesn't have: cannons,
wormholes, targets, items, currents, rotating gravity and decorations. Team maps with treasures play as
*Capture the ball*, maps with race timing as *Race*, and everything else as *Dogfight*.
